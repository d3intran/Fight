## 1. 算法（`Scripts/anim/atk_10_lol_upper_retarget.py`）

逐骨、按层级顺序：

```
Ws_rest = 源骨静止世界旋转      Ws_cur = 源骨当前世界旋转
Wt_rest = 目标骨静止世界旋转
G_bone  = Wt_rest · Ws_rest⁻¹          # 每根骨自己的「静止朝向对齐」
M_des   = G_bone · Ws_cur              # 目标骨应有的世界朝向
basis   = (W_par_cur · local_rest_rel)⁻¹ · M_des
pb.rotation_quaternion = basis.to_quaternion()
```

**为什么是「每骨 G_bone」而不是一个全局 G**：两套骨架的静止姿势本来就不同
（LoL 是 T-pose 系、Darius 是 A-pose 系，骨骼 roll 约定也不同）。
全局 G 只能修整体朝向，修不了每根骨自己的朝向约定。
`G_bone = Wt_rest·Ws_rest⁻¹` 让「静止时目标 = 目标 rest」自动成立，
数学上等价于标准重定向器的「local delta 传递」，但**不需要额外的 retarget pose**。

**脊柱 2→3 的显式分配**（不交给自动）：
`Spine1 → spine_01`、`Spine2 → spine_03`、`spine_02 = slerp(spine_01, spine_03, 0.5)`。

**骨盆平移也搬**（源在攻击中骨盆下沉 53cm、前冲 72cm）：
按身高比 `SCALE = 目标身高 / 源身高 = 0.009505` 缩放，投影到各自体坐标系后平移。

## 2. 踩到并修掉的 4 个真 bug（都是实测出来的）

| # | bug | 症状 | 修法 |
| :--- | :--- | :--- | :--- |
| **1** | **打键写在 `bake()` 之后** | `frame_set` 把 pose 冲掉 ⇒ **整段动画被冻成最后一帧**（74 个键全是同一个姿势），渲染出来是一坨 | 打键必须在 bake 循环**内部**（`bake(Gx, key=True)`） |
| **2** | **导出时把 GLB 的源网格一起导出** | 源网格高 190 单位、目标场景才 1.7 单位 ⇒ 画面里**一坨巨球**挡住角色 | 记下「导入目标 FBX 前已有的网格」，导出只留目标自带的那 7 个 |
| **3** | **没搬骨盆平移** | 骨盆停在 rest 高度，但腿按源的姿势蜷着 ⇒ **角色悬空、脚离地** | 骨盆 world 位置一并传递（见 §1） |
| **4** | **FBX 导出参数缺 `apply_unit_scale`** | 单位不缩放 | 照抄项目已验证的 `anim_80` 导出参数 |

渲染脚本（`Scripts/anim/atk_12_bl_render.py`）也修了两处：
- **取景**不能用全骨包围盒 —— 骨架里有 `SnapWeapon` / `Throne` 之类远点，会把镜头拉飞；
  改成用「头顶 z − 脚底 z」定高度。
- GLB 渲染要按**材质名**剔除 `Wolf_Mat` / `Throne_mat`（神王皮肤的狮子/宝座变身子网格），
  否则画面全是狮子和宝座。

## 3. ⚠️ 当前的数字指标**不可用作门禁**（要改）

我原本定的指标是「**体坐标系下关节连线方向夹角**」。实测它**量不准**：

| 段 | 源 rest 与目标 rest 的夹角（指标下限） |
| :--- | ---: |
| spine_low / spine_up / neck | 17.1° / 20.2° / 3.2° |
| arm_*1 / arm_*2 / arm_*3 | 43.4° / 7.6° / 39.1° |
| leg_*1 / leg_*2 | 5.9° / 20.0° |
| **leg_*3**（脚→趾） | **108.1°** |

两套骨架**静止姿势本身就差这么多**（T vs A、脚趾骨约定不同），所以指标的**下限就是 17~43°**。
量出来的 `ALL 均值 71.2° / P90 120.2° / max 171.5°` 里**大部分是静止姿势差，不是传递误差**。

**旁证**：`extra_yaw` 扫描说 180° 比 0° 好（57.2° vs 71.2°），但**视觉上 0° 才是对的**（180° 会把身体转反）。
⇒ 这个指标确实不可靠。

**下一版指标**（能把静止姿势差消掉）：
比较「**各自相对自己 f0 的姿态变化**」——
`源(f) 相对 源(f0) 的关节连线方向变化` vs `目标(f) 相对 目标(f0) 的方向变化`。
两个都从各自的静止姿势出发，静止差自动约掉。
